# ADR-002：进阶地面路线与运行时调度权威边界

- 状态：Accepted
- 日期：2026-09-12
- 对应设计：`进阶地面路线与车机协同玩法_长期设计.md` V1.3

## 决策

基础配送继续使用现有单路线任务与百分比推进。进阶配送使用独立的候选路线和运行时地面状态，不修改冻结任务制品：任务生成时保存三条候选路线，启动时冻结一条监管车基线，玩家车辆随后通过版本化调度命令切换剩余路线。

所有候选路线、道路锚点、强制节点、监管车计划、命令接受状态、有效路线版本、奖励扫掠和教程完成证据均以后端为权威。前端只提交候选 ID 或目标意图，不提交可执行折线。

运行时算路不得阻塞仿真 Tick。每个会话最多一个请求在途，只保留最新待处理意图；`commandSequence` 防止旧意图回退，`routeVersion` 标识真正激活的路线。算路失败时车辆继续上一条有效路线。

轻型无人机任务的强制节点顺序为起飞点、返航点、终点。重载 VTOL 不应用前两个节点。监管车始终沿启动时冻结的候选路线行驶，不复制玩家绕行。

## 兼容与发布

缺省规划模式为 `BASIC`。新增数据库结构保持向前兼容，旧任务不回填。进阶能力由后端开关分为技术预览、教程 02 和正式玩法，首发区域仅为翡翠湖校区。

教程 02 由服务端运行证据完成；教程 00/01 的旧本地完成记录只允许一次性迁移，`SKIPPED` 不解锁教程 02。

## 后果

进阶仿真需要维护按距离推进的地面状态，并在检查点回溯时一并恢复。回放必须读取已保存的路线版本，不能重新调用外部路线服务。基础模式保留原路径，降低现有玩法回归风险。
