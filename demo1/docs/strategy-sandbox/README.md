# 城市空地协同物流运营沙盘：规划入口

本目录保存当前产品与技术建设基线。

## 产品定义

> 在合肥真实三维城市空间中，经营一家同时拥有地面车辆和低空运输设备的物流公司，通过接单、配载、调度、交付、结算和投资建立高利润、高准时率且具备风险韧性的城市配送网络。

正式名称：**城市空地协同物流运营沙盘**
英文名称：**Urban Air-Ground Cooperative Logistics Sandbox**
简短品牌名：**SkyFleet Logistics**

## 不可偏离的基线

- 百度地图三维能力是主地理底座，近期只建设合肥试点区域。
- 玩家经营一家公司，每个主要界面都要支持有后果的经营或调度决策。
- 优先完成“任务生成—资产绑定—配送—结算—再投资”的纵向闭环。
- 任务、资产、位置、电量、收入、成本和处罚只由后端权威仿真判定。
- 所有资金变化进入可追溯、幂等的公司账本。
- 随机内容由 Seed、规则版本和生成器版本共同约束，并可确定性复现。
- AI 只解释后端计算出的方案，不改变资格、排序、数值或执行状态。
- 真实设备命令链路未接入前，系统不得暗示已经控制现实设备。
- 第三方地图、模型、图片和视频必须完成来源与许可治理。

## 开发前检查

1. 本轮改动补全经营闭环的哪一环？
2. 玩家新增了什么选择，以及这个选择会带来什么结果？
3. 权威状态、幂等键、规则版本和回放数据由谁负责？
4. 是否保持访客、公司、任务和资产的隔离边界？
5. 是否存在未声明的外部服务、密钥、资产授权或现实设备依赖？
6. 单元测试、构建、容器健康与浏览器可达性如何验证？

具体需求与本目录冲突时，以长期建设指引和已经批准的 ADR 为准。重大调整必须记录问题、决策、迁移影响和验证方式。
