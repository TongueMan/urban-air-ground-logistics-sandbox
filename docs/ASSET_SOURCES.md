## 治理要求

- 第三方资源不得因源代码使用 Apache-2.0 而被重新许可。
- 新模型进入仓库前必须登记稳定 ID、来源、作者、许可证、SHA-256、大小和场景统计。
- 未明确允许公开分发的资产必须保持在 `.gitignore` 中。
- 百度和 DeepSeek 的真实密钥不属于项目资产，不得写入源码、镜像或 Git 历史。
- 视频哈希见 [ASSET_HASHES.txt](ASSET_HASHES.txt)，模型哈希以运行时注册表为准。
